# Практическая работа №1

Весь код в **src/Main.java**: BMI, оба варианта обменника по курсу 11,91 и класс Car со всеми методами из задания. Папка `src` нужна для распознавания исходников в VS Code.

В IntelliJ IDEA создайте Java-проект, вставьте код в `Main.java` и запустите `main` зелёным треугольником.

Либо из этой папки в терминале:

```powershell
javac -encoding UTF-8 src/Main.java
java -cp src Main
```

Выберите пункт меню 1–4; 0 завершает программу. Вводите числа, количество юаней - целое. Дробный вес и рост можно вводить с точкой или запятой.

Примеры: 100 юаней = 1191 руб.; 21 юань = 250,11 руб.; 22 юаня = 262,02 руб.; 11 юаней = 131,01 руб.

Проверка BMI при росте 200 см: вес 72 → недостаточный вес; 74 → норма; 100 → избыточный вес; 120 → ожирение. Границы взяты из PDF.
